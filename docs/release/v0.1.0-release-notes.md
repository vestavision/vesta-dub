# Vesta Dub 0.1.0 release notes

Published at https://github.com/vestavision/vesta-dub/releases/tag/v0.1.0. The tag `v0.1.0` points at `ff4874a5862dfa6699d6fa2a83a6b3044684cccb`. This is a public beta. It was not submitted to the Chrome Web Store.

Earlier notes called this package a local candidate and recorded NO-GO for the private development clone. That clone was not pushed. The package hash is in `docs/release/v0.1.0-publication.md`.

## Voices

- Antalia-2 Mini is the default voice.
- EMA Lightning is the experimental second voice. It loads when a slot uses it.
- Piper Fahrettin is removed from the extension, the voice list, and the package. A saved Piper choice becomes Antalia on the primary slot and EMA Lightning on the second slot.
- Manual start remains the default.

## Translation

- The default is local English-to-Turkish translation in the browser. It does not need an API key.
- The first run downloads 15.1 MB of pinned model data. Later translation uses that cache and does not send caption text out.
- Google Cloud Translation API v2 is optional. It runs only after you select it and save your own key.
- The unofficial Google Translate client is not included and is not a fallback. Local and Cloud do not fall back to each other.
- A missing or rejected Cloud key stops dubbing, restores the original volume, and does not speak English.
- HTTP 429 still stops the session. It does not resume by itself.

## Install

End users prepare the unpacked extension with `install.sh`. That script checks the pinned zip and extracts it. It does not load the extension. Chrome and Brave still need Developer Mode and Load unpacked. The steps and the pinned command are in the README. The published assets are the `v0.1.0` GitHub release.

Developers:

```bash
npm ci
npm test
npm run compile
npm run package:release
```

`package:release` writes `release/vesta-dub-0.1.0-rc.zip` and a byte-identical `release/vesta-dub-0.1.0.zip`. Load `.output/chrome-mv3` only for development. Listening steps are in `docs/release/browser-acceptance.md`.

## Known limits

One synthetic voice for every speaker. No local speech recognition. Local translation still needs the model download, and YouTube still needs the network. EMA is experimental. The package is large because the two voice models, ONNX Runtime, and the Bergamot worker are bundled. Background playback still depends on the browser leaving the YouTube video running.

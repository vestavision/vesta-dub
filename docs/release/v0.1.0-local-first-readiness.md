## Translation behavior

Default is Local on a fresh install and when the stored mode is missing or anything other than the exact string `cloud`. A saved Cloud key does not switch the mode by itself. Local failure does not call Cloud. Cloud without a key does not call Local. Empty Turkish text is not spoken. A missing Cloud key, when Cloud was explicitly selected, stops the session and restores volume.

The offscreen document reports status to the service worker (`OFFSCREEN_STATUS_PUSH`). The service worker writes `chrome.storage.local`. A direct storage write from the offscreen document did not reach the popup in Brave 155.

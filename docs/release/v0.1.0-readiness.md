## Product that this candidate ships

A Manifest V3 extension that dubs supported YouTube watch pages into Turkish from available captions and local speech models. Manual start is the default. Antalia-2 Mini is the default voice. EMA Lightning is selectable and marked experimental. Piper Fahrettin is not selectable. English captions use the local translator by default. Cloud Translation is optional and requires the user's own key.

## What is in good shape

- Stop, pause, seek, and navigation invalidate the synthesis generation. Recovery tests cover stale audio after those events.
- Empty Turkish text is not synthesized.
- A terminal translation failure calls the same stop path that restores ducked volume.
- A missing bundled voice file is not downloaded. The translation weights are a separate pinned download and are not a substitute for a missing voice.
- The P6 audio-capture worklet is not in `public/` and is not web-accessible.
- The duplicate `wasm/` mirror is removed from the packaged output. The runtime points ONNX at the extension root.
- Diagnostics in the popup stay behind an explicit toggle.
- No analytics endpoint was added.

## What was left out

`scripts/export-public-repo.mjs` copies the working tree and skips:

- `.git`, `node_modules`, `.output`, `.wxt`, `dist`
- `tests/artifacts/` (local recordings and evaluation files)
- `tools/` (review pages and research helpers)
- `public/wasm/` (byte-identical copy of ONNX Runtime files already at `public/`. The package script removes that duplicate from the zip.)
- `youtube_page.png`
- research notes directly under `docs/` (the release notes under `docs/release/` stay)
- research scripts, including every script that opens the Piper ONNX path
- tests that read `tests/artifacts/`, `tools/`, or the Piper weight, and `tests/**/*.mjs`

The kept build scripts are `sync-bergamot.mjs` and `package-release.mjs`. The kept test helper is `scripts/p5.2-sentence-shadow.ts`.

Release zips are gitignored. A local copy of `release/vesta-dub-0.1.0.zip` may sit in the clean working tree for the owner to upload. It is not part of the Git history.

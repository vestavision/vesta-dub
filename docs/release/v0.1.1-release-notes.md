# Vesta Dub 0.1.1 release notes

Public beta. This is not a Chrome Web Store listing. `v0.1.0` was already published at https://github.com/vestavision/vesta-dub/releases/tag/v0.1.0. This release does not replace that record.

Copyright 2026 Vesta Vision. Security contact: security@vestavision.io. Source license: Apache-2.0. Third-party terms stay in `NOTICE` and `THIRD_PARTY_LICENSES.md`.

## What changed

- Spoken form for "Tesla Model Y" is "Tesla Model Ye". The written caption stays "Tesla Model Y". "Ah" and "Uh-huh" stay. "Oh" remains "Aa". "Mm-hmm" remains "hı hı". Model S and Model X candidates stay off.
- Caption activation selects the player track object after `loadModule('captions')`. It does not pass a bare language code. It does not call the player while the tab is hidden.
- A missing video element on the same watch URL no longer tears the dubbing session down.
- Context grouping stays off. No new translator, diarization system, speech recognizer, or voice was added.

## Browser

These are real YouTube runs in an isolated Brave 155 profile (Chromium 155.0.8059.40) with the 0.1.1 unpacked build. They are not unit tests. The normal Brave profile was not used.

On `https://www.youtube.com/watch?v=zjkBMFhNj_g`, two fresh loads played the video and accepted Start, then stayed on “preloaded track unavailable” with no Turkish speech. Stop returned the session to idle. Dubbing had not ducked the video.

A third fresh load received the English track (1,283,031 bytes, 1,704 cues), showed Turkish text, and started Antalia speech while the watch tab stayed visible. The observed window was about 19 seconds, not a five-minute listen. During caption load the player volume moved from about 0.24 to 1. Dubbing then lowered it to 0.2. Stop restored it to 1 and left the video playing.

A five-minute hidden-tab run without a playhead reset was not repeated for this build. The earlier isolated run still stands: the playhead restarted from about 43 seconds to 0, then continued with thinning speech. That background result is fail. See `docs/release/known-limitations.md`.

## Known limits

Translation can be awkward. Context grouping is off. There is one synthetic voice for every speaker. EMA Lightning is experimental. A hidden watch tab can restart YouTube near the beginning; five continuous minutes of hidden dubbing without that reset did not pass, and the normal Brave profile was not tested. Stop restores the saved original volume when dubbing had ducked it. The extension does not call `video.play()`.
